# Checkpoint

Review the current session and repository state.

Update `PROJECT_STATUS.md` with only the information needed to continue the project.

Include:

- Current project status
- Work completed in this session
- Work currently in progress
- Important decisions made
- Reasons for important design decisions
- Requirements or requirement changes
- Important files created or modified
- Known bugs or unresolved issues
- Environment or configuration details needed to continue
- Current priorities
- Recommended next steps

Do not copy the conversation transcript.

Keep the file concise and useful.

Update or remove obsolete information instead of continuously appending old information.

Before finishing:

1. Verify that `PROJECT_STATUS.md` reflects the actual repository state.
2. Make sure completed items are marked completed.
3. Make sure unresolved items are clearly identified.
4. Record enough information for another engineer or a new Codex session to continue the work.
